# Corrections and challenges (draft)

## Anyone can challenge anything

No account is needed. Choose a type:

| Challenge type | Example |
|---|---|
| **Factual error** | "The vote was 98–70, not 97–71." |
| **Missing evidence** | "This claim has no source," or "A better source exists." |
| **Unsupported assumption** | "This assumes every school district will opt in." |
| **Unfair characterization** | "This misstates what opponents actually argue." |
| **Outdated** | "A substitute changed this section." |

- Each challenge is attached to the specific sentence or card.
- An email address is optional (only so we can reply), and **it is deleted when the challenge closes**.
- Forms are protected against spam and automated abuse.

## What happens next

| Step | Target |
|---|---|
| Challenge appears publicly as **Received** (personal details removed) | immediately |
| First response | **within 2 business days** |
| Resolved: *corrected*, *clarified*, *no change (with reasons)*, or *duplicate* | **within 7 days**, or a dated update explaining the delay |

- While a substantive challenge is open, the item shows **Disputed**.
- During legislative crunch periods these targets still apply.

## Change classes

Every change to published content creates a new **revision**. The old version stays viewable, and a diff
shows exactly what changed. Every revision has a class:

| Class | Meaning | Notice |
|---|---|---|
| **Typo** | Spelling or formatting; meaning unchanged | In history only |
| **Update** | New facts (for example a substitute, a vote, a signing) | Dated "Updated" note |
| **Correction** | We were wrong | **Prominent notice** at the top of the item and an entry in the site-wide **corrections log** |
| **Re-evaluation** | Same facts, changed judgment (for example an evidence label) | Notice explaining why |

Corrections need a second independent verification pass
([verification protocol](../process/verification-protocol.md)). We correct quickly and visibly, inside the
text rather than in a footnote.

## Our records

We publish quarterly:
- the number of challenges by type and outcome;
- response times;
- corrections per 100 claims.
