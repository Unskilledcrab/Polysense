# 0010: Licensing

- **Status:** Proposed (confirm before public beta)
- **Date:** 2026-11-08

## Decision

| What | License |
|---|---|
| Code | **Apache-2.0** (carried over from the original repository) |
| Our published content (explanations, workspaces, policies) | **CC BY 4.0**, so others can reuse it with attribution (as Democracy Club's open model shows, reuse multiplies reach) |
| Third-party data | **Keeps its source license.** Open States data is public domain or CC0; LegiScan is CC BY 4.0, so attribution is shown; government records are public |
| Copyrighted analyses we cite | Not redistributed. We keep the URL, the hash and short cited excerpts only |
| Dependencies | Permissive or compatible only; no AGPL in the application ([0013](0013-security-baseline.md)) |

## Consequences

Partners and newsrooms can republish our explanations. We must display attribution for CC BY sources.
