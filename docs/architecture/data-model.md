# Data model (design; refined by manual trials before implementation)

Internal and public IDs are **UUIDv7**, generated by the app. Outside IDs live in a crosswalk table.
Time validity uses Postgres range types (`daterange`, `tstzrange`), and **btree_gist exclusion
constraints** prevent overlaps: no two boundaries for the same division and purpose, and no seat with two
holders at once.

## (a) Civic and reference data

| Entity | Purpose | Key fields |
|---|---|---|
| **Division** | The identity of a political area | `ocd_id` (`ocd-division/country:us/state:ga/sldl:54`), kind, name |
| **DivisionBoundary** | A dated shape of a division | division, plan (e.g. "2023 SB 1EX"), **purpose** (`representation` or `election`), `valid` daterange, geometry (SRID 4326), source snapshot |
| GeoidCrosswalk | Census GEOID → OCD ID | geoid, vintage, division |
| Organization | Chamber, committee, agency, Governor's office | classification, parent |
| Person / Actor | Officials; Actor also covers non-official speakers (organizations, witnesses) | Actor optionally links to a person or organization |
| Membership | A seat or committee role | person, organization, division, role, party, `valid` range |
| Session | A biennium and year | `2027_28`, year, legislative-day → date map (filled in once resolutions set it) |
| Bill / BillVersion | Legislation and its text versions | (session, `HB 123`); version label, LC number, snapshot |
| BillAction / VoteEvent / PersonVote | History and votes | date, legislative day, chamber, motion, result |
| Meeting / AgendaItem | Hearings and floor sessions | start (with timezone), status, livestream, agenda snapshot; item → bill, with how it was extracted |
| ExternalId | Links to other systems | (scheme, value) unique: `ocd-person/…`, `ocd-bill/…`, LegiScan IDs and change hash, legis.ga IDs |

## (b) Participation

| Entity | Purpose | Key fields |
|---|---|---|
| **Opportunity** | One dashboard item | kind (vote, testify, written, contact, attend, observe), **power** (decide, input, observe), decision, target, window (opens, closes, **precision**, timezone), audience divisions or statewide, steps, status, `last_verified_at`, source |
| ParticipationGuide | Reusable how-to for one body | body, text, `verified_at` |
| Topic / TopicTag | The everyday-concerns taxonomy | slug, reason for the tag |

"Your member sits on this committee" is **computed** (membership ∩ your districts ∩ meeting), not
stored.

## (c) Evidence and knowledge

| Entity | Purpose | Key fields |
|---|---|---|
| Source | A document or page we rely on | url, publisher, **type** (primary-government, secondary-research, advocacy, news), license |
| **Snapshot** | An immutable capture | source, `sha256`, storage key, archive URL, `fetched_at`, HTTP status and headers |
| **Passage** | The unit we cite | snapshot, `extractor_version`, ordinal, page, character range, `text_sha` |
| Decision / Option | The IBIS issue and its options | question, deciding organization, linked bill versions; `is_status_quo` |
| Argument | One case for or against an option | option, stance, **provenance** (documented or anticipated), actor, quote passage |
| Claim / ClaimRelation | Toulmin parts and AIF-style links | role, **type** (factual, predictive, values, computed, editorial), evidence strength × agreement, low/high/unit; relation supports, attacks or undercuts |
| Sentence / Citation | Published prose and its sources | ordinal, type; passage span, `cited_text`, `verified_by` |

**Constraint:** a documented argument must have an actor and a quote passage. An anticipated argument
must have **no** actor. A database CHECK enforces both.

## (d) Trust and workflow

| Entity | Purpose | Key fields |
|---|---|---|
| **Revision** | Append-only public history | object (kind, uuid), sequence, canonical JSON, `sha256`, `parent_sha`, **change_class** (typo, update, correction, re-evaluation), reason, editor, AI run, notice |
| AIRun | AI provenance | requested model, served model, `prompt@sha`, effort, input passage IDs, hashes of the raw request and response, usage, stop_reason, batch_id |
| GateResult / Review | Automated checks and human verdicts | check, pass/fail, details · verdict per citation (supports, partial, no, wrong span), reviewer, second reviewer |
| Challenge | Public error reports | revision and anchor, type, optional email (deleted on close), status, `due_by`, resulting revision |
| SourceWatch | Change detection | last sha256 → marks dependent items "source changed: re-review" |
| CoverageDecision | Topic-selection log | candidate, rubric scores, decision, reason |
| AuditLog | Every editorial action | who, what, when, from where |

## How revisions work

1. Editors work on **mutable draft rows**.
2. **Publishing** serializes a whole *publishable bundle* (a decision workspace, an opportunity, or a
   policy page) to canonical JSON, hashes it, and appends a Revision that points to the previous one.
3. **Public pages render only from Revisions.** Diffs are between consecutive Revisions.
4. The table is **append-only**: a trigger rejects UPDATE and DELETE, and the runtime database role lacks
   those privileges.
5. The **corrections log** is a view over revisions with `change_class = correction`.

Per-row history tools (such as django-simple-history) are the wrong level of detail for public diffs.

## Modeling traps

1. **An OCD ID is not a shape.** In 2028 the map legislators serve under and the map for the next
   election may differ at the same time.
2. **Georgia's legislature is biennial.** Bills from 2027 stay alive in 2028, and bill numbers reset each
   biennium.
3. **A decision is not a bill.** Substitutes, companion bills and the budget break a one-to-one mapping.
   Claims cite a specific bill version, so a new substitute marks the workspace stale.
4. **Don't share claims across workspaces** in the pilot.
5. **Never re-split a snapshot into passages in place.** A new extractor version creates new passages.
6. **A "legislative day N" isn't a calendar date** until an adjournment resolution sets it.
7. **Licenses carry through to the data.** LegiScan data is CC BY, so attribution goes wherever it's
   shown.
8. **Never store addresses,** in tables, logs or error reports.
